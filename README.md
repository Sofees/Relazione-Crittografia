# Relazione-Crittografia
Relazione realizzata per il corso di Crittografia presso l'Università di Bologna.

Il lavoro approfondisce i principi della crittografia moderna, utilizzando il data breach di Epik del 2021 come caso di studio per analizzare le vulnerabilità dei sistemi informatici e le possibili soluzioni.

Particolare attenzione è dedicata al Secret Sharing, agli schemi di Shamir e Blakley e alle loro applicazioni nella protezione delle chiavi crittografiche.

**Argomenti principali:**

  - Crittografia simmetrica e asimmetrica

  - Funzioni hash e protezione delle password

  - Certificati digitali, firme digitali e SSL/TLS

  - Secret Sharing e sicurezza perfetta

  - Applicazioni reali e crittografia post-quantistica
